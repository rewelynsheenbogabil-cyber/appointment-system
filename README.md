# Web-Based Appointment System 📅
A responsive, single-file appointment management web application designed for clients and administrators.

✨ Features:

User Authentication: Secure Login & Registration with input validations (contact number and password matching).

Profile Management: Users and admins can update their profiles and upload profile pictures.

Appointment Booking: Clients can book specific services (Consultation, Check-up, Maintenance) with daily limits and time slot restrictions.

Admin Dashboard: Admins can manage appointment statuses (Confirm, Complete, Delete) and filter appointments by date and service type.

Assistant Chatbot: Built-in bot providing instant answers regarding location, operating hours, and service pricing.
